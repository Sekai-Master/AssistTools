## はじめての周回

みんなでライブは最大 5 人で一緒にライブを行い、ひとりでライブより多くの報酬を得られます〔公式・2020年9月から〕。
「協力ライブ」という呼び名はプレイヤーの通称で、公式の説明は見当たりません。
同じ曲を繰り返す「周回」に初めて入る流れを、8 つの手順に分けて案内します〔プレイヤーの間で〕。

### 1. 部屋を探す・作る

**協力ライブの周回で使うのは、基本的にカスタムルームではなくプライベートルームです〔走っている人の実感〕。**

- ルームを選ぶ画面には、①フリールーム、②ベテランルーム、③プライベートルーム作成、カスタムルーム作成、④ID入室などが並びます〔ゲームの画面〕。
- ①フリーは「他のプレイヤーと一緒にライブ」、②ベテランは「総合力の近いプレイヤーとライブ」と画面で案内されています〔公式〕。
- 部屋主が X で並走者を募り、それを見た人が部屋に入る形は「ツイ募」と呼ばれ、Discordでの支援とは作法が別になります〔プレイヤーの間で〕。
- Discordでは、イベントごとに走る人（ランナー）を支える「支援鯖」が今の主流です〔走っている人の実感〕。

### 2. 募集の文を読む

**部屋に入れてもらえるかは、先頭（リーダー）のスキルや内部値（リーダーを含む5枚のスキル合計）で基本的に決まります〔走っている人の実感〕。**

- 「主」は募集した人の編成、「募（求）」は入室条件、「↑」は以上、「@1」〜「@4」は残りの募集人数です〔プレイヤーの間で〕。
- 主・募の「%」はイベントボーナスではなくリーダーのスキル値で、「募：星4」ならリーダーのスキルは何でも構いません〔プレイヤーの間で〕。
- 「火消し（自然回復したライボを回して使うこと）×」は、数回だけ入ってすぐ抜けないでほしいという意味です〔プレイヤーの間で〕。
- 募集の文にある用語（SFC・条件外・判定強化✖など）について、公式の説明は見当たりません。

### 3. 部屋に入ったら

**ルームの待機画面では、左下の①スタンプのアイコンを押すとスタンプの欄が開きます〔ゲームの画面〕。**

- スタンプの欄には「キャラクター」「テキスト」「お気に入り1〜3」「履歴」のタブや、並びの切り替え・絞り込みのボタンなどが出ます〔ゲームの画面〕。
- お気に入りスタンプのタブは3つあり、ユニットやキャラクター別の絞り込みも使えます〔公式・2024年6月から〕。
- 右上のメニューの「スタンプ」からお気に入りの欄を編集でき、20種類×3つのセットまでよく使うものをまとめて保存できます〔走っている人の実感〕。
- 例として、ある走者の周回用のお気に入りには「ありがとう」「またね〜」「ごめん…行くね」「大丈夫だよ」などが入っています〔ゲームの画面〕。

### 4. 炊き数を決める

**①炊き数（1回のライブで使うライブボーナスの数）で、獲得するイベントポイントの②倍率が決まります〔ゲームのデータ〕。**

- ①炊き数は最大10まで選べます。イベントポイントの②倍率は0炊きで1倍、1〜5炊きは1個あたり5倍（5炊きで25倍）、6炊きで27倍、10炊きで35倍です〔ゲームのデータ〕。
- 2024年9月28日に4〜6炊きのイベントポイント倍率が引き上げられました（5炊きは23倍→25倍）。報酬・EXPの倍率とは別の表です〔公式・2024年9月から〕。
- 倍率の改定で5炊きまではロスが無くなったため、資源が潤沢なら5炊きで走ることが多くなっています。時間が無いときや目指す順位がとても上のときは7や10で走ります〔走っている人の実感〕。
- 消費の画面には「報酬・EXP」と「イベントP」の②倍率が別々に出ます（画像の例では5消費で両方25倍）。マッチング中や曲決定後の数字が出ている間にも①炊き数を変えられます〔ゲームの画面〕。

### 5. 曲が始まったら・アンコール

**協力ライブでは1曲にスキルが6回発動し、参加5人が1回ずつと最後の「アンコール」1回になります〔このサイトの計算〕。**

- 1〜5回目のスキルの発動順は、2023年7月のv2.7.5からランダムになったとされています〔プレイヤーの間で〕。
- 6回目のアンコールは、その位置の直前にスコアが一番高かった人が担当します。支援サーバーでは、高い総合力と安定したプレイが要るアンコール担当も決めます〔走っている人の実感〕。
- 実効値（協力ライブで実際に乗るスキルの値）が強い人がアンコールを取るほうが全員の得になります。自分が強くない立場なら、難易度を下げるという考え方もあります〔プレイヤーの間で〕。
- スキルの発動順のランダム化とアンコールの決まり方について、公式の説明は見当たりません。

### 6. 抜ける・謝る・返す

**部屋を抜けるときは、各キャラの「またね」「ありがとう」系や穂波の「ごめん…行くね」を使います〔走っている人の実感〕。**

- 咲希の「おつかれさま！」は部屋主が解散するときだけ使う合図で、参加者は押しません〔走っている人の実感〕。
- 「謝罪不要」と書かれた部屋では謝るスタンプは要りません。回線の不調や一時退室などで謝っている人には、KAITOの「大丈夫だよ」を返すのが一般的です〔走っている人の実感〕。
- 抜けるスタンプを押す時機は、最後の曲の前か退室の直前かなど、プレイヤーの間で揃っていません〔プレイヤーの間で〕。
- スタンプの意味や使い分けはすべてプレイヤーの慣習で、公式の説明は見当たりません。

### 7. 休憩とリフレッシュゲージ

**リフレッシュゲージが100%になると、イベントポイントとバッジを得られなくなります〔公式・2026年2月から〕。**

- イベントのトップ画面の左上に①ゲージの値（画像の例では0.3%）が出ます。押すと②全回復までの時間（画像の例では「全回復まで30:00」）が出ます〔ゲームの画面〕。
- 手動のライブやマイセカイの採取でゲージが増え、曲が長いほど1回の増加が多くなります。オートライブとチャレンジライブでは増えず、100%でもポイントを得られます〔公式・2026年2月から〕。
- 前のプレイから5分たつと休憩とみなされ（5分は2026年3月10日のイベントから）、休憩が累計30分になるごとに一定量減ります〔公式・2026年2月から〕。
- 休憩30分ごとにゲージは約8.33%減り、100%から0%まで6時間かかります〔このサイトの計算〕。

### 8. 自分のポイントを確かめる

**①獲得したイベントポイントは、スコア係数に③イベントボーナス、曲の基礎点、②ライブ報酬の倍率を順にかけて決まります〔このサイトの計算〕。**

- ライブの結果の画面の例では、アンチユー（HARD）でスコア1,376,057が出ています。次の画面に②ライブ報酬5倍、③イベントボーナス+395%、①獲得4,655 P、累計などが出ます（ライブの種類は写っていません）〔ゲームの画面〕。
- この例をひとりでライブとして式で計算すると、スコア係数168に（100＋395）÷100をかけて831.6になります。そこにアンチユーの基礎点112（×112÷100）をかけて切り捨てた931に、1炊きの②5倍をかけると①4,655 Pで1の位まで一致します〔このサイトの計算〕。
- 協力ライブでは、自分のスコアだけでなく他の4人の合計スコアもスコア係数に入ります（他4人の合計544万点で加点の上限16）。強い人と一緒に叩くと1回のポイントが上がるのはこのためです〔このサイトの計算〕。

くわしく → 1.2
