## 0. はじめに

### 0.1 このガイドの読み方と確かさの印

このガイドはプロセカのイベント周回（イベラン）や協力ライブの周回・支援に入ってみたい人に向けた知識ガイドです。公式の仕様と、ゲーム内のデータ、サイトでの計算・実測、実際に走っている人の慣習や実感を区別して記載します。時期によって変わった仕様には、確認できる範囲で「いつから」という時期を添えています。

本文ではそれぞれの記述の出どころを次の印で示します。

| 本文の印 | 出どころ |
|---|---|
| 〔公式〕／〔公式・YYYY年M月から〕 | 公式サイトやゲーム内のお知らせ、公式Xの生放送告知画像、ゲーム内のルール説明画像 |
| 〔ゲームのデータ〕 | ゲームのマスタデータ（multiLiveLobbies・boosts・stamps）およびその表からの計算 |
| 〔このサイトの計算〕 | SekaiMasterのコードや実測・集計データ |
| 〔ゲームの画面〕 | 運営者が撮ったゲームの画面で確かめたこと。画面に写っている範囲だけを書きます |
| 〔走っている人の実感〕 | 周回の当事者である、このサイトの運営者の実感・慣習 |
| 〔走っている人の見立て〕 | このサイトの運営者による推測（本文でも「〜と思われます」と表記します） |
| 〔プレイヤーの間で〕 | プレイヤーの間で共有されている知識や慣習（公式の裏付けがないもの） |

また、公式のお知らせ（409件）・ゲーム内のお知らせ（88件）・公式生放送の告知画像（250枚）を調べても記述が確認できなかった事柄については、本文中に「公式の説明は見当たりません」と記します。

### 0.2 ライブの呼び名（「みんなでライブ」と「協力ライブ」）

公式の名称は「みんなでライブ」です〔公式・2020年9月から〕。最大5人のプレイヤーとマッチングして一緒にライブを行うモードで、「ひとりでライブ」よりも多くの報酬を得られます〔公式・2020年9月から〕。チアフルカーニバルイベントの開催中は、「みんなでライブ」が「チアフルライブ」になります〔公式・2025年12月から〕。

一方で、プレイヤーの間でよく使われる「協力ライブ」という呼び名については、公式のお知らせ409件の中に1件も無く、公式の説明は見当たりません。なお、「マルチライブ」という言い方は、2023年3月7日の質問箱の回答に1回、2025年11月25日の公式生放送の告知画像にも出ています〔公式〕。

このガイドとSekaiMasterのサイト内では、通称である「協力ライブ」という呼び名を使います。
