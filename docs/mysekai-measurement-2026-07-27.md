# マイセカイ採取ポイントの実測（2026-07-27）

対象: `src/pages/analyzer/lib/mySekai.ts` の単価式・メモリ値の検証
測定環境: チュートリアル進行中の別アカウント／**イベントボーナス 406.7%／ワールドパス無し**
出典: Nori による実機計測 2026-07-27（イベント211 瑞希チャプター走行中の並行調査）

---

## 結論

**既存実装の式・定数はすべて正しい。** 加えて、UIの注記に残っていた「通常スタミナとブーストスタミナで獲得ポイントが変わるらしい」という未確定情報は**正しく、差は5倍**と確定した。

## 単価の式（確認済み）

```
coefTalent = floor((1 + 総合力 / 450000) × 10) / 10
baseVal    = floor(coefTalent × (1 + ボーナス / 100))
単価       = baseVal × 100      … 通常スタミナ（水色）
           = baseVal × 500      … ブーストスタミナ（オレンジ）／ワールドパス所持
```

本測定では **ボーナス406.7%・パス無し・通常スタミナで 800 Pt/メモリ**。
既存コメントの較正値「総合力313,460 / ボーナス416% → 800 Pt」と一致する。

## メモリ値（実測）

| 対象 | メモリ | 通常スタミナ | ブースト | 状態 |
|---|---|---|---|---|
| 木・岩 | 1.0 | 800 | 4,000 | ✅実測 |
| キラキラ・樽 | 0.5 | 400 | 2,000 | ⚠️未検証（チュートリアル環境では出現せず） |
| 宝箱・工具箱・草・花 | 0.2 | 160 | 800 | ✅実測 |

複数種を混ぜた採取でも合算が1Ptもずれないことを確認した（宝箱1・工具箱4・花1・岩2・木3 = 6.2メモリ = 4,960 Pt）。

## ゲージの仕様

- マイセカイのゲージは**円を10分割**して描画される。**1分割＝1メモリ**
- **木は6回叩いて1本伐採、ゲージが1メモリ進む**
- **ライブボーナス1消費 → スタミナ1メモリ回復＋ブースト状態**（速度も大幅上昇）
- 1周（10メモリ）＝ 8,000 Pt（本測定の条件で）

## ブーストは5倍（新規確定）

ブースト状態（オレンジゲージ）では**全対象が一律5倍**になる。対象ごとに倍率が変わることはない。

```
通常  岩1個 = 800 Pt
ブースト 岩1個 = 4,000 Pt   （5.0倍）
```

**ワールドパス所持者は常時ブースト状態**（速度・ポイントとも上昇）との証言があり、既存定数 `MYSEKAI_MULTIPLIER_WORLD_PASS = 500` はこれと整合する。つまり実態は**「パスで5倍」ではなく「ブーストで5倍」**であり、パス所持者は常時ブーストなので結果的に一致していた。

## 実装への示唆

**非パス民もライブボーナスを使えば5倍になる**が、現行の `hasWorldPass` フラグではこの選択肢を表現できない。ただし**モードとして組み込むのは不適切**と判断した（Nori判断・2026-07-27）。理由:

- パス所持は固定パラメータだが、非パス民のブースト使用は**「LBを何本マイセカイに割くか」というユーザーの可変の意思決定**であり、着地計算の入力として持つと目的から外れる
- LB効率で比較すると**ライブ5焚きが 13,380 Pt/LB、マイセカイ・ブーストが 4,000 Pt/LB** で、**ライブが3.3倍有利**。最適解は「マイセカイにLBを回さない」に収束するため、選択肢として提示する価値が薄い

したがって**現行実装（非パス民は通常スタミナ前提の800Pt）が妥当な既定値**である。

### UI注記の書き換え案

現在の `MySekaiStep.tsx` / `PointAnalyzer.tsx` の注記は「通常スタミナ（水色）とブーストスタミナ（オレンジ）で獲得ポイントが変わるという情報があり…」と未確定の書き方になっている。確定したので以下に置き換えられる。

> ブーストスタミナ（オレンジ）使用時は5倍になります。この計算機は通常スタミナ前提です。ワールドパス所持者は常時ブースト扱いのため「ワールドパス有り」を選んでください。

## 未検証・今後の課題

- **0.5メモリ枠（キラキラ・樽）**。チュートリアル環境では出現しないため未測定。本編環境で要確認
- **採取速度（メモリ/分）**。ポイント側は確定したが時間側が未測定。「マイセカイスタダ」（イベント開始時に島の資材を刈り取る戦術）の価値を数値化するには、島1周の所要時間と総メモリ数が要る
  - トップランカーの証言では**10分前後**で行うもので、全部を回収するのではなく**遠くのアイテムは効率が悪いので拾わない・ルート選定が重要**とのこと。時間あたりの価値がライブを上回るのは、この短時間の刈り取りに限った話と理解される
- `mySekai.ts` が意図的に無視している「1日あたりのスタミナ上限」は、採取速度とスタミナ回復量が分かればモデル化できる
