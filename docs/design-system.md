# デザインの規約（余白・字・アイコン・幅・影）

> **下書き（2026-11-05）。Nori の確認前。** 確定したらこの注記を外す。

画面を足す・直すときの決まり。色と影の値そのもの（トークン）は `src/index.css` の `@theme` が正本で、ここでは「どれをどこに使うか」を決める。明暗テーマは [theming.md](theming.md)、画面遷移は [motion-system.md](motion-system.md)。

## なぜ作るか

2026-11-05 まで、色・影・書体のトークンはあったが、余白の刻み・字の段・アイコンの大きさ・ページの幅は決まっていなかった。その結果（2026-11-05 にコードを数えた値）:

- 余白のクラス（`p`・`px`・`py`・`gap`・`space-y`・`mt`・`mb`、`src/pages` と `src/components`）で、4px の倍数でない値（`1.5`・`0.5`・`2.5`）が 232 か所ある。ページによって 4px の倍数の割合が 54〜92% とばらつく（競合サイトとの計測、`Documents\spica-reference\compare-assisttools`）
- 字の大きさは 12px（`text-xs`）が 336 か所で、14px（`text-sm`）の 202 か所より多い。補足の大きさが本文より多く使われている
- 枠（`Panel`）の見出しが 14px の灰色（`text-sm text-slate-500`）で、中の項目のラベルより弱く見える

トップを作り直したとき（#194）に、各機能ページの余白とアイコンの釣り合いも直したいという話になった（Nori 2026-11-05）。その直しの物差しとしてここに置く。案の一部は Argon（Gemini 4 Argon）の提案を、今のコードの値と照らしてから採った。

## 1. 幅

| 種類 | 幅 | 使う所 |
|---|---|---|
| ふつう | `max-w-3xl`（768px） | 入れて結果を読む1列のツール（いまの `ToolPage` の既定） |
| 広い | `max-w-6xl`（1152px） | 表・グラフ・2列が要るツール（`ToolPage` の `wide`） |
| トップ | `max-w-5xl`（1024px） | ハブだけ |

- 3つ以外の幅を足さない。1列のページで1つだけの入力欄（`select` など）は `max-w-md`（448px）で止める（横に間延びさせない）
- グラフや表が窮屈なツール（ボーダー予測）は「広い」に移す。説明の文だけは 1 行 40 字前後に抑える

## 2. 字の段

| 段 | 大きさ・太さ | 使う所 |
|---|---|---|
| ページの見出し | 20px・700（`.unit-title`） | ページに1つ |
| 枠の見出し | 16px・700 | `Panel` の `title`。**灰色にしない**（いまの 14px・灰色から上げる） |
| 本文・項目のラベル | 14px・400（ラベルは 500） | 入力のラベル、結果の文 |
| 補足 | 12px・400 | 注記・単位・凡例。**12px より小さくしない** |

- 数字（ポイント・順位・時間）は `font-num`（Geist Mono、等幅）。日本語は M PLUS Rounded 1c のまま
- 結果の主役の数字だけ大きくしてよい（24px 以上）。段を増やす代わりに、数字の大きさで主従を出す
- 括弧書きの補足を見出しに入れない（スマホで 2 行になる）。補足の段へ出す

## 3. 余白

- **4px の倍数だけを使う。** 主に 8・16・24・32px（Tailwind の `2`・`4`・`6`・`8`）。細かい調整だけ 4・12px（`1`・`3`）
  - `*-0.5`・`*-1.5`・`*-2.5` は、1px の線やバーの中の位置合わせなど、余白でない所に限る
- ページの見出し→最初の枠: 24px（`ToolPage` の `mt-6`、いまのまま）
- 枠どうしの間: 24px（`space-y-6`、いまのまま）
- 枠の内側: スマホ 16px・PC 24px（いまの `p-5 sm:p-6` は 20/24px。スマホを 16px に）
- 枠の中のまとまりどうし: 16px。ラベル→入力欄: 8px（詰めるときは 4px）
- 操作のボタンは、関係する枠の中に置く。枠の外の地に1つだけ浮かせない

## 4. アイコン

- Material Icons（filled）の1系統。文字は CSS で出す（`<span className="material-icons" data-icon="…" />`）。合字の元の文字（`insights` など）を要素の文字に入れない。検索エンジンが見出しやリンクの文字として読む（#190・#194）
- 大きさは3段: ページの見出しの中 22px／一覧の行・ボタン・見出しの横 20px／12px の札の中 16px
- 色は文字と同じ灰色（`text-slate-500`）。ユニットの色をアイコンに塗らない（色は分類の印に使う、5節）

## 5. 色

- ユニットの色は**分類の印**に使う: ページの見出しの帯、一覧の分類の下線、カードの上端の線、データの印（トップのバー）
- 本文の字・アイコン・ボタンの地には使わない
- 1つの画面で目立たせる色は、そのページのユニットの色1つにする

## 6. 影（ニューモーフィズム）

- **段は「外の枠＋中の1段」まで。** `.neu-panel` の中は、押すもの＝`.neu-raised` か、入れる所・空き枠・溝＝`.neu-inset` のどちらか1段
- 浮いている＝押せる、凹んでいる＝値を入れる・埋める所。この対応を崩さない
- 枠の中にさらに浮いた行、その中に浮いたボタン、のような三重にしない。区切りが要るなら線（`divide-y`）にする

## 7. 量の出し方

- 主な結果と主な入力のほかは畳む（`<details>`）。長い履歴・検証の表は、要約と直近 1〜2 件だけ見せる
- 説明の文は、そのページで一度だけ。同じ断りを枠ごとに繰り返さない。防御的な注意書きを足さない
- 画面に出す文字を減らすときは、数字・バー・図に置き換えられないかを先に考える（トップの残り時間とボーダー、#194）
