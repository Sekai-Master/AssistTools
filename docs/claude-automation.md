# Claude API による自動化（2026-10-08〜）

Max プランの毎月の API クレジット（Max 5x で月 $100・繰り越し無し・Claude Code には使えない）を、席にいなくても動く仕組みに回す。4つとも GitHub Actions で動き、**鍵（`ANTHROPIC_API_KEY`）が無いあいだは何もしない**。

| | いつ | 何をする | 出す先 | 中身 |

| ② X の自動投稿 | 毎日 12:05 JST | 72時間前の main と比べ、新しい版（MINOR 以上・更新履歴の日付が7日以内）と新しく公開された曲（1曲1本）を知らせる。id が版・曲ごとなので二重にならない。**画像つき**（2026-10-10〜）: 新曲は Bot が描く新曲カード（ジャケ写・曲名・作者・ユニット色）、版は更新履歴の「追加」でいちばん先に名前が出るツールの画面（無ければ更新履歴のページ）を Bot が本番で撮る（`xposts.ts` の `songPayload`・`releasePayload`。描き方は sekaimaster-bot の `docs/border-relay.md`） | X（投稿キュー経由・X だけ） | `.github/workflows/x-auto-post.yml`・`scripts/claude/x-auto-post.ts`・`xposts.ts` |

## 決めごと

- **事実はデータから、言い回しだけ Claude**。曲名・版番号・ボーダーの数字はプログラムが埋める。Claude の答えは型（頭の書き出し・URL・字数・ハッシュタグの有無）で確かめ、合わなければ②は決まった型の文面に落とし、③は積まない
- **承認なしで出す文面は、型と安全の両方で確かめる**（`xposts.ts` の `safeForX`）。メンション（@ ＠）・山かっこ・自分のサイト以外のリンクやドメインを含むものは出さない。曲名・イベント名のように外から来る文字にも同じ確かめを当てる
- **比べる元が読めない・空のときは何も出さない**。1回の本数にも上限（版2本・曲3本）があり、超えたら何も出さずに失敗にする（全部を「新しい」とみなして過去の版や全曲を流す事故を止める）
- ①④の Issue に書く前に、メンションを全角に、画像を消し、GitHub と自分のサイト以外のリンクを伏せる（ログやデータ元のコミットの文は外から来るので、そこに書かれた指示に Claude が従わないよう囲んで渡す）。①は同じ件を20時間以内に書いていれば Claude を呼ばない
- **Claude を審判にしない**。④の候補を採るかどうかは、いままでどおり前向き検証（`workers/border/src/fit.ts`）が決める（2026-10-08 Nori と合意）。試すときは候補として足して、解析ジョブの採点を見る
- **承認なしで出してよい**（2026-09-30 Nori）。まずい投稿は Nori が消す
- **版の告知は②が出す**ので、セッションで版を上げたときに手で告知しなくてよい（二重になる。②の id は `x-release-v<版>`）
- 鍵とプロンプトの中身はログに出さない（Actions のログは公開）。出すのは使ったトークン数だけ
- ①の診断は推測を含む。直すときは実物で確かめる

## 鍵と費用

- 鍵は Console で作り、Vaultwarden と GitHub の Secrets（`ANTHROPIC_API_KEY`）にだけ置く
- 毎月の API クレジットを使い切ると、買ったクレジットに流れる。**Console で自動チャージを切り、使える額の上限を置く**
- 見込み: ①は 1 回数十円（失敗したときだけ）、②は版があった日だけ数円、③④はイベントごとに数十円。月 $100 にはまず届かない
- モデルは `scripts/claude/client.ts` の `MODEL`（Sonnet 5）

## 止めたいとき

GitHub の Secrets から `ANTHROPIC_API_KEY` を消せば、4つとも何もしなくなる（②の新曲の告知は Claude を使わないので動き続ける。止めるなら `x-auto-post.yml` を無効にする）。
