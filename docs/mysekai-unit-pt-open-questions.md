# マイセカイ単価の未解決点（実測待ち）

ステータス: **β（未確定）**。確証が取れるまで UI に注記を出している（`MySekaiStep.tsx` / `PointAnalyzer.tsx`）。
確定したらこのファイルを更新し、注記を外すか内容を修正すること。

## 現在の実装

`src/pages/analyzer/lib/mySekai.ts` の `calculateUnitBasePt(talent, bonus, hasWorldPass)`:

```
coefTalent = floor((1 + 総合力 / 450000) * 10) / 10
baseVal    = floor(coefTalent * (1 + ボーナス / 100))
単価        = baseVal * (ワールドパス所持 ? 500 : 100)
```

引数は3つだけで、**どのスタミナで採取するかは考慮していない**。

## 確定していること

基礎の式（倍率 ×100 側）は実測で裏付けがある。`mySekai.ts` 冒頭に記載の実測値を再検算して一致を確認済み:

| 総合力 | ボーナス | 実測 | 計算 |
|---|---|---|---|
| 297,159 | 615% | 1100 Pt | `floor((1+0.66035)*10)/10 = 1.6` → `floor(1.6*7.15) = 11` → 11×100 = **1100** ✓ |
| 313,460 | 416% | 800 Pt | `1.6` → `floor(1.6*5.16) = 8` → 8×100 = **800** ✓ |

どちらもワールドパス無し（×100）側の値。

## 未解決 1: 通常スタミナ（水色）とブーストスタミナ（オレンジ）で獲得ポイントが変わる

**現在の実装はこれを一切区別していない。**

- 水色 = 1日1回全回復する通常スタミナ。オレンジ = ライブボーナス／回復ドリンク／クリスタルで足したブースト分。
- 「ブーストスタミナでは採取スピードが上がるほか、獲得できるポイントなどが増えます」
  （[ゲームエイト・マイセカイ](https://game8.jp/pjsekai/663229)）
- 「水色のスタミナを使った採取で貰えるポイントはかなり少ないです（5分の1くらいな気がする）。
  ライブボーナスや回復ドリンク、クリスタルを使ってブーストしたオレンジのスタミナだとまあまあポイント貰えます」
  （[プロセカな雑記帳](https://ameblo.jp/kokokororosekai2020/entry-12885837611.html)）
  ※ 体感値であり、測定値ではない。

**影響**: ポイント調整で「木を12個採れ」と出しても、水色スタミナで採ると想定より大幅に少なくなる可能性がある。
「目標ちょうどに着地」という本ツールの根幹保証が崩れる。

## 未解決 2: ワールドパスの ×5 という倍率に出典がない

`constants.ts` の `MYSEKAI_MULTIPLIER_WORLD_PASS = 500` にはコメント「ワールドパス所持で5倍になる」以外の根拠が無い。
同ファイル冒頭には「ここの値はゲーム側の仕様に対応しているので、変更するときは必ず一次情報で裏を取ること」と
書いてあるが、この定数だけ出典が示されていない。

ワールドパス自体は実在し、採取まわりに効果があることは確認できる:
> ワールドパスはマイセカイだけでなくゲーム本編にも一部効果をもたらす。具体的には、
> **素材採取時に得られるライブP、獲得イベントP、獲得イベントバッジ、プレイヤーランクEXPの増加**
> （[ゲームエイト・ワールドパス](https://game8.jp/pjsekai/663335)）

ただし**倍率が5倍であるという記述は見つかっていない**。

**懸念**: コミュニティが言う「水色はオレンジの5分の1くらい」と、実装の「ワールドパスで5倍」が、
どちらも約5倍で別々の軸に付いている。**取り違えの可能性がある**（ブーストスタミナの効果を
ワールドパスの効果として実装してしまっている疑い）。断定はできないが、確認するまで信用すべきでない。

## 影響しないと考えられる範囲

リフレッシュゲージ側（`src/pages/refresh/lib/gaugeModel.ts` の `mySekaiMaterial: 700`/スタミナ）は
おそらく無関係。ゲージの蓄積は獲得ポイントではなく**スタミナ消費量に依存する**という情報があるため、
スタミナ種別では変わらないと考えられる。ただしこれも未検証。

## 決着させるための実測手順

総合力・イベントボーナス・ワールドパス状態を固定したうえで:

1. **軸①（スタミナ種別）**: 水色スタミナだけで木を1メモリぶん採取 → 獲得イベントPtを記録。
   次にオレンジスタミナで同じく1メモリぶん採取 → 記録。比を出す。
2. **軸②（ワールドパス）**: 加入前後で同一条件の採取を記録して比を出す。
   既に加入済みなら加入前の記録がない限り測れないため、まず軸①だけでも確定させる価値がある。

測定できたら:
- 倍率が確定 → `constants.ts` に出典コメント付きで反映し、`calculateUnitBasePt` にスタミナ種別の引数を追加。
- UI にスタミナ種別の選択を追加（採取に使うスタミナを選ばせる）。
- 本ファイルと UI のβ注記を更新・削除。
