# 1周のうち、曲以外にかかる秒数（オーバーヘッド）

- **状態**: 有力（実測1系統。環境差の幅がまだ取れていない）
- **確かめ方**: Nori の実測から逆算。値の正本は [`src/lib/overhead.ts`](../../src/lib/overhead.ts)
- **出典**: このサイトの計測（2026-08-11 統合 / 2026-08-21 に計測ツールを公開）
- **最終更新**: 2026-08-21
- **関係するツール**: [/lap](https://sekaimaster.pages.dev/lap) [/ranking](https://sekaimaster.pages.dev/ranking) [/plan](https://sekaimaster.pages.dev/plan) [/worktime](https://sekaimaster.pages.dev/worktime)

## 結論

1周の所要時間は **曲の長さ ＋ オーバーヘッド**。オーバーヘッドの内訳はライブの種類で変わる。

| ライブの種類 | 既定値 | 中身 |
|---|---|---|
| 協力ライブ（手動） | **54秒** | マッチング・部屋待ち・支援者交代・ロード・リザルト |
| ソロのオート | **33秒** | ロードとリザルト送りだけ |
| チャレンジライブ | **33秒** | ソロと同じ扱い |

協力ライブを**詰めて回した場合**の理論値は **38秒**。実測平均（54秒）との16秒差が、そのまま
部屋待ちと支援者交代のコストになる。

## 根拠

すべて独りんぼエンヴィー（74.8秒）を基準にした逆算。実測平均 28回/時 から
`3600 ÷ 28 − 74.8 ≒ 53.8` 秒。

**この値は1人ぶんの計測**で、環境（回線・端末・部屋の立て方・時間帯）で動く。
そのため 2026-08-21 に[周回ラップ計測](https://sekaimaster.pages.dev/lap)を公開し、
**自分の値を測って上書きできる**ようにした。実測が既定より速い人にとっては、
他のツールの見積りが保守的すぎることになる。

## 使いどころ

- **同じ数字を別の場所で二重に持たない。** 過去にランキングが20秒・周回プランが54秒と
  2.7倍食い違っていたことがある（2026-08-11 に `src/lib/overhead.ts` へ統合）。
  値を変えるときはそのファイルだけを直す
- 1周の単価（Pt）は編成で決まるが、**1時間あたりの周回数はオーバーヘッドで決まる**。
  時速Pt＝単価×3600÷(曲長＋オーバーヘッド)

## 未解決

- オートのリザルト送りを詰めた場合の下限
