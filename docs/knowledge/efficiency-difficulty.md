# 「効率難易度」は何を指しているのか

- **状態**: 確定（ただし**前提つき**。下記の2つは別物）
- **確かめ方**: `musicScoreData.json` 全707曲の総当たり（2026-08-21）＋ 出典記事の読解
- **出典**: 集計はこのサイトの配信データ。前提の整理はめんま氏の記事 <https://privatter.net/p/9923207>
- **最終更新**: 2026-08-21
- **関係するツール**: [/ranking](https://sekaimaster.pages.dev/ranking)

## 結論

「効率難易度」という言葉は、**前提の違う2つの意味**で使われている。混ぜると逆の結論が出る。

| | 前提 | 答え |
|---|---|---|
| **A. 理想値** | 1枠 かつ 巻き込み成功 | 曲ごとに違う（テルユアは赤、シャルルは緑 など） |
| **B. 素の値** | 2〜5枠 または 巻き込みなし | **ほぼ常に一番上の難易度** |

X で共有されている難易度表は **A**。このサイトのランキングが出しているのは **B**。

## 根拠（Bの総当たり結果）

難易度が変わっても曲の長さは同じなので、効率の大小は基礎スコアの大小でそのまま決まる。
2難易度以上のデータがある707曲で:

- **683曲**は難易度が上がるほど基礎スコアも上がる
- 最高効率の難易度の内訳: MASTER 583曲 / APPEND 123曲 / EXPERT 1曲

つまり B の前提では、答えは「APPEND があれば APPEND、無ければ MASTER」にしかならない。
**Bの意味で「効率難易度を検索する道具」を作っても、中身が無い**（2026-08-21 に予定を取り下げた理由）。
